# umtymp-calculus1-f26

Local mirror of the
[UMTYMP Calculus 1 (Fall 2026) folder](https://doenet.org/sharedActivities/pcKKBXm3cunporFKSGZD5D/kP4hWuV6gEEfpWrhmVjEYa)
on doenet.org. See the repo's main README for setup. From the repo root:

```
python3 scripts/doenet_pull.py --root umtymp-calculus1-f26
python3 scripts/doenet_push.py --root umtymp-calculus1-f26 --all --dry-run
```

Only the loose activities in each folder are mirrored. The problem sets
on doenet.org (including the one assigned to a class) hold their own
copies of these activities, which pushing here does not update.
